Cover Forge is an offline browser web app that turns a photo and a caption into GTA-style multi-panel poster cover art: pick a layout (Hero + 2, Hero + 3, 2×2 grid, Triptych), load your own photo or a bundled sample, choose a grade (sunset, neon night, retro), set the bold outlined poster caption, and export a real PNG at 1080×1080, 1080×1350 or 1920×1080. Pure hand-written HTML/CSS/JS — no libraries, no uploads, no network.

## Run it

```sh
node serve.ts
```

Then open the local address it prints and use the app in your browser.
